## [AgentCore CLI로 AI 에이전트 개발부터 배포까지 – Kiro CLI, Claude Code와 함께 쓰는 워크 플로우](https://aws.amazon.com/ko/blogs/tech/bedrock-agentcore-cli/)
- 회사: AWS
- 본문 요약: 2026년 10월 28일 정식 출시된 npm 기반 AgentCore CLI 1.0(본문 기준 1.1.0)으로 Amazon Bedrock AgentCore 에이전트의 수명 주기 전체를 터미널 하나에서 다루는 방법을 정리한 글입니다. 수명 주기는 create(CDK 코드가 포함된 프로젝트 생성) → dev(8080 포트 로컬 서버, 핫 리로드, 브라우저 인스펙터) → deploy(CodeZip 또는 CodeBuild 컨테이너 빌드 후 CloudFormation 스택 배포) → invoke(CLI, boto3 InvokeAgentRuntime, OAuth Bearer 토큰) 4단계이고, 여기에 status/logs/traces 운영 명령이 붙습니다. 이후 agentcore add로 memory, gateway, evaluator, policy, config-bundle, harness 같은 리소스를 하나씩 붙이고, agentcore eval로 온디맨드·배치 평가와 A/B 테스트를 돌리는 방식까지 다룹니다.
- 주목할 point: 모든 명령이 비대화형으로 동작하고 --json 출력을 지원해, Kiro CLI나 Claude Code 같은 코딩 에이전트가 '코드 수정 → dev → invoke → 오류 로그 확인' 루프를 스스로 돌릴 수 있습니다. 연결 방법은 CLI 직접 실행, 스킬·플러그인 설치(Kiro 파워, Claude Code aws-agents 플러그인), AgentCore MCP 서버 연결 3가지입니다. 실무 주의점도 짚습니다. 기존 Python Starter Toolkit은 같은 agentcore 명령을 쓰므로 먼저 제거해야 하고, deploy는 배포 전에 확인을 묻지 않으니 cdk diff로 미리 확인해야 하며, --session-id는 33자 이상이어야 하고, 리소스 철거는 remove all 다음에 deploy를 실행해야 실제로 이뤄집니다.
