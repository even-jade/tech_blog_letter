## [모니터링 시스템 안정성을 높인 InnoDB Cluster 기반 DB 고가용성 구축 사례](https://on.com2us.com/tech/monitoring-db-innodb-cluster-high-availability/)
- 회사: 게임빌컴투스플랫폼
- 본문 요약: 24시간 운영되는 서비스의 이상 징후를 가장 먼저 감지하는 모니터링 시스템 자체의 DB를 MySQL InnoDB Cluster 기반 고가용성 구조로 개선한 사례다. 모니터링 애플리케이션이 MySQL 인스턴스에 직접 접속하지 않고 MySQL Router를 통해 클러스터에 접근하도록 구성했으며, Single-primary 모드의 Group Replication으로 Primary 장애 시 Secondary 노드가 자동으로 새 Primary로 승격된다.
- 주목할 point: Primary 장애가 발생해도 MySQL Router가 변경된 클러스터 상태를 인식해 애플리케이션 설정 변경 없이 새 Primary로 요청을 전달하는 구조라, 모니터링 데이터 수집·조회·장애 감지가 중단될 가능성을 낮췄다는 점이 핵심이다. "모니터링 시스템 자체의 안정성이 서비스 운영 안정성과 직결된다"는 문제의식이 인상적이다.
- keyword: #MySQL #InnoDBCluster #GroupReplication #고가용성
